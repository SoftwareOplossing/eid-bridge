Let's Peppol eID Bridge
Windows 11 x64

GET STARTED

1. Save your work and restart Edge or Chrome after installation.
2. Enable the official Web eID extension when your browser asks.
   Firefox users install it from the Firefox Add-ons store.
3. Connect your card reader, insert your Belgian eID and open:
   https://be.letspeppol.org/onboarding

If the extension is missing, onboarding offers its official store link.
Internet access is needed for the browser to download the extension.
Browser settings or company policies may require a manual installation.

Edge: https://microsoftedge.microsoft.com/addons/detail/gnmckgbandlkacikdndelhfghdejfido
Chrome: https://chromewebstore.google.com/detail/web-eid/ncibgoaomkmdpilpocfeponihegamlic
Firefox: https://addons.mozilla.org/firefox/addon/web-eid-webextension/

HELP AND LOGS

Help and onboarding: https://be.letspeppol.org/onboarding

Logging is always enabled in your Documents folder:
LetsPeppol eID Bridge\Logs\LetsPeppol-eID-Bridge.log

The Start menu provides links to onboarding, these instructions and Documents.
Review logs before sharing them with support. Keep your PIN private.

INSTALLATION AND REMOVAL

The application and its libraries are installed in:
C:\Program Files\LetsPeppol eID Bridge

Administrator approval is required. A separate Belgian middleware installation
is not needed. The installer protects existing Web eID host registrations;
uninstall a conflicting desktop application before installing this one.

Uninstall through Windows Settings > Apps > Installed apps.
Your logs remain in Documents. You can remove the browser extension from your
browser's extension settings if you no longer need it.
